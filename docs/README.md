## この製品の保証がどこで担保されているか

仕様書ではなく **CI** です。`.github/workflows/android.yml` が、INTERNET 権限の不在・通信ライブラリの
不在・提出用印刷モジュールが共有インテントや一時ファイルを持たないこと・見た目の退行（基準画像との
ピクセル比較）を、push のたびに機械で検査します。詳しくはリポジトリの [README](../README.md) を参照してください。
