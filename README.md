# プライバシーカメラ (PrivacyCamera)

**免許証・保険証・マイナンバーカード・通帳を撮るための、通信できないカメラアプリです。**

このアプリには **INTERNET 権限がありません**。撮った写真をネットワークへ送ることが、
設定の問題ではなく**技術的に不可能**です。原本は端末内で暗号化され、本人認証を通した
ときだけ、このアプリの中で復号して表示されます。

- 撮影 → 即座に AES-256-GCM で暗号化（鍵は Android Keystore の中にあり、端末外へ取り出せない）
- 保存先はアプリ専用の内部ストレージ。Google フォト等のメディアスキャナからは**見えない**
- 表示は `BiometricPrompt`（生体認証、無ければ端末の PIN / パターン / パスワード）を通したときだけ
- クラウドバックアップ・端末間移行からも除外（`allowBackup=false`）
- スクリーンショットと履歴サムネイルを禁止（`FLAG_SECURE`）

> 設計方針: 画像の中身を解析して個人情報を「判定」することはしません。
> **このアプリで撮った時点で機密**とみなし、無条件に暗号化・マスキングします。

## 「通信しない」を、言葉ではなく機械で担保しています

この製品の主張は、**あなたが自分で確かめられます**。

| 主張 | 確かめ方 |
|---|---|
| INTERNET 権限が無い | [`app/src/main/AndroidManifest.xml`](app/src/main/AndroidManifest.xml) に `android.permission.INTERNET` が無いこと。配布 APK 自体も `aapt dump permissions` で確認できます |
| 通信ライブラリが1つも入っていない | CI が毎回、**出荷される release ランタイムの依存ツリー全体**（Lite / Pro 両方）を検査し、okhttp / retrofit / ktor / volley / grpc / cronet 等を見つけたらビルドを落とします |
| 提出用印刷が「共有」や一時ファイルを使わない | CI が `print/` 配下に `ACTION_SEND` / `FileProvider` / `cacheDir` / `filesDir` 等が現れたらビルドを落とします |
| 見た目が勝手に変わっていない | マスク結果・透かし・ロック画面を基準画像とピクセル比較（Roborazzi + 自作 Bitmap ゴールデン） |

検査は [`.github/workflows/android.yml`](.github/workflows/android.yml) にあります。
**人間のレビューではなく CI が落とす**ので、見落としでこの約束が破れることがありません。

配布 APK には SHA-256 チェックサムが添付されます（[Releases](../../releases) の各リリースノートに記載）。
ダウンロードした APK のハッシュと突き合わせれば、改変されていないことを確認できます。

## Lite と Pro

1 つのコードベースから 2 つの製品を出し分けています（判定点は `BuildConfig.IS_PRO` の1箇所だけ）。

| | Lite（無料） | Pro（有料） |
|---|---|---|
| applicationId | `com.istech.privacycamera.lite` | `com.istech.privacycamera` |
| 保存枚数 | 上限あり（入れ替え運用） | 無制限 |
| PII マスキング | 撮影時の自動モザイクのみ | **主役機能**（モザイク／ぼかし／黒塗り・強さ・範囲指定の高度編集） |
| 書き出し | 移行用の平文 ZIP（原本同梱・取り扱い注意） | パスフレーズ暗号化の完全バックアップ（`.pcbak`） |
| 取り込み | — | Lite からの移行・任意画像のモザイク化・暗号化バックアップからの復元 |
| 提出用の印刷 | — | あり（隠し機能・下記） |

**別 applicationId なので、Lite と Pro は同じ端末に併存インストールできます。**

### 主な画面
- **カメラ** … CameraX のプレビューとシャッター。撮った瞬間に暗号化＋マスク保存。
- **ギャラリー** … マスク済みサムネイルの一覧。
- **ビューア** … 最初はマスク表示。目のアイコンで本人認証を通すと、アプリ内でだけ正規表示。
- **マスク編集**（Pro） … 原本を変えずにマスクだけ作り直す。仕様は写真メタに残り再編集できます。
- **ゴミ箱** … 削除は 30 日間保持のソフト削除（誤削除の救済はバックアップではなくゴミ箱の責務）。
- **アクセスログ** … 閲覧・復号・書き出し・削除を端末内に暗号化して記録。端末の外へは出ません。

### 提出用の印刷（Pro・隠し機能）
本人確認書類を公的機関等へ提出するために印刷する機能です。既定では**機能自体が非表示**で、
ギャラリーのドロワー最下部のバージョン表示を 7 回タップすると設定が現れます。

出力されるのは常に、**手で範囲マスクした上に透かし（提出先・日付・目的外利用不可の文言）を
焼き込んだ「提出用複製」**だけです。無地の原本は端末の外に出ません。出力経路は Android の
印刷機能（`PrintManager`）のみで、共有も PDF 書き出しも一時ファイル生成もありません。

> **注意**: 印刷データは端末の印刷サービス（プリンタドライバ等）に渡ります。本アプリ自体は
> 依然として通信できませんが、印刷サービスがネットワークプリンタを使う場合、そこから先は
> 本アプリの保護範囲外です。自宅プリンタへの直接印刷を推奨します。

詳細仕様は [`docs/2026-07-04_仕様_提出用出力機能.md`](docs/2026-07-04_仕様_提出用出力機能.md) を参照してください
（[`docs/`](docs/README.md) には、どれが現行仕様でどれが経緯の記録かの索引があります）。

## 入手する

- **BOOTH（署名済みビルド・更新・サポート）**: 準備中
- **GitHub Releases**: 署名済み APK と SHA-256 をここで公開します → [Releases](../../releases)（**本リポジトリでの初回リリースは準備中**）

> **⚠ β版を使っている方へ**: 正式版は applicationId が変わるため、Android から見て**別アプリ**です。
> 上書き更新にはならず、β版のデータは新しいアプリからは読めません（アプリ専用ストレージのため）。
> **β版をアンインストールする前に、アプリの書き出し機能でデータを取り出してください**
> （Pro＝暗号化バックアップ `.pcbak`、Lite＝Pro 移行用の書き出し）。取り出したファイルは正式版の
> 取り込み機能から復元できます。

Pro のソースを含め全体が Apache-2.0 で公開されています。ご自分でビルドして使うこともできます。
BOOTH でお支払いいただく分は、**ビルド済み・署名済みの APK と、以後の更新とサポート**に対する対価です。

## 自分でビルドする

Android SDK が必要です（Android Studio 推奨）。

```bash
echo "sdk.dir=/path/to/Android/sdk" > local.properties
./gradlew assembleDebug          # Lite / Pro 両方の debug APK
./gradlew installLiteDebug       # 無料版を端末へ
./gradlew installProDebug        # 有料版を端末へ
```

リリースビルドの署名は環境変数で駆動します（`RELEASE_KEYSTORE_PATH` /
`RELEASE_STORE_PASSWORD` / `RELEASE_KEY_ALIAS`）。**署名鍵はこのリポジトリに含まれません——
暗号化した形でも置いていません。** 公開した暗号文は取り消せず、総当たりに永久に晒されるためです。
鍵は GitHub Secrets にのみ存在し、CI がビルド時に復元します。手元にビルドした APK は当然ながら
あなた自身の鍵で署名されたもので、配布物とは署名が異なります。鍵が無い場合、リリースビルドは
単に未署名で出力され、ビルドは壊れません。

### テスト
```bash
./gradlew :app:verifyRoborazziProDebug
```
エミュレータ不要（JVM 上の Robolectric）。基準画像の更新はローカルではなく
**Record Golden Images** ワークフロー（`workflow_dispatch`）で行います
（ローカルのフォント差による偽の差分を避けるため）。
