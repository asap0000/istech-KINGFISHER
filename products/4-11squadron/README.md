# Wingsスクリーンセイバー：第４−１１飛行隊

Windows用の3DCGスクリーンセイバーです。

「Wingsスクリーンセイバー」は、各国のアクロバット飛行隊の展示飛行を描くシリーズです。第1作「第４−１１飛行隊」では、編隊飛行とスモークの軌跡を描きます。飛行の形・時間・距離は模式表現です。

本作は個人制作の非公式作品であり、航空自衛隊および防衛省との関係はありません。映画『劇場版 ブルーインパルスの空へ』の興行宣伝を目的とした作品でもありません。

実行ファイルは `4-11squadron.scr` です。BOOTHでの頒布を予定しています。

本作の実行ファイルとデータは、このリポジトリのApache-2.0ライセンスの対象外です。本作の利用条件は頒布物に同梱します。
